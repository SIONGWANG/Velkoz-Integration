# v1.24.7 报告 — 读取规则改回逐条横排

- 日期：2026-11-26
- 分支：`1.24`
- 版本：`1.24.7`
- 基线：`v1.24.6`（`4e48eb5`）

## 一、调整原因

v1.24.6 把「自定义读取规则」改成了标签页 + 单条编辑。虽然高度变小，但每次只能看到一条配置，改多个槽位要反复切换，实际操作更麻烦，不符合使用习惯。

v1.24.7 取消标签页和切换下拉，恢复为「所有配置同时可见」，但把每一项压缩成一条短横排，避免输入框横跨整页。

## 二、改动

### 1. 所有配置同时显示
- 不再使用标签页。
- 不再使用「编辑块 / 编辑槽位」下拉。
- 文件夹块、图片槽位、文本框全部按顺序列出。

### 2. 每项一条紧凑横排
- 文件夹块：`序号 · 类型 · 长度 · ↑ ↓ ✕`
- 图片槽位：`序号 · 后缀 · 扩展名 · ✕`
- 文本框：`序号 · 后缀 · ✕`
- 标签隐藏，通过占位符和悬停说明解释字段含义。
- 输入框使用固定宽度，后缀/扩展名不再拉满整页。

### 3. 宽屏与窄栏自适应
- 宽屏（冷启动设置页）：整块内容最大宽度限制为 620px，行内控件排成一条。
- A 区窄栏（加载数据后的设置面板）：控件自动改为自适应宽度并换行，不会超出栏宽。
- 判断方式：`_render_settings_panel` 的 `key_prefix` 为空时视为窄栏，冷启动 `cs_` 前缀视为宽屏。

### 4. 清理无效项
- 移除「块标记」输入。该字段只被保存、没有参与文件夹匹配或任何展示，属于无效配置。
- 已有配置中的 `label` 字段不会删除，保存时原样保留。

### 5. 保留内容
- 顶部规则彩色块概览保留。
- 「🧪 测试匹配」折叠区保留，正则仍放在其中。
- 保存 / 恢复默认并排显示。

### 5. 修复点 × 删除错行
- 原因：删除后剩余行沿用原来的 widget key，浏览器把旧输入框状态套到新的一行，看起来像删除了最后一条。
- 修复：增加 `_sr_gen` 代次，增删/排序后所有行使用全新的 key，确保「点哪条删哪条」，剩余内容显示正确。

## 四、已知限制

1. A 区窄栏下，每条配置会自然换行成多行，页面高度会增加；配置操作建议在冷启动宽屏设置页完成。
2. 输入框标签为了紧凑而隐藏，新用户需要看占位符或悬停提示；占位符在填写后会消失。
3. 文件夹块仍只提供精确长度；范围输入仅在已有配置包含 `min/max` 时保留。
4. 移除「块标记」输入后，已有标签无法再编辑，但该字段本来不参与匹配。
