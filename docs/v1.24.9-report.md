# v1.24.9 报告 — 导出按二级分类分文件夹 + 二级分类快捷键更灵敏

- 日期：2026-11-27
- 分支：`1.24`
- 版本：`1.24.9`
- 基线：`v1.24.8`（`6f5ec26`）

## 一、需求来源

参考另一版本 `Vel_Koz_V2.1.0` 的导出能力：导出合格数据时可以勾选「按二级子类分文件夹」，导出结果按 CSV 的「二级」字段分成多个子文件夹。

同时修复现有二级分类快捷键（D/F/G…）不灵敏的问题。

## 二、导出按二级分类

### 使用方式

导出管理面板新增勾选框：

```
📂 按二级分类分文件夹
```

- 不勾选：保持原结构 `导出目录/图片ID/`
- 勾选：`导出目录/二级分类/图片ID/`

### 规则

- 二级分类取自当前 CSV 的「二级」字段（与质检时选择的二级分类一致）。
- 二级为空或 NaN：归入 `_未分类`。
- Windows 不允许的字符 `\ / : * ? " < > |` 及控制字符替换为 `_`。
- 分类名首尾空格、结尾的点会被清理，避免资源管理器无法打开。
- 勾选状态在本次会话内保留，rerun 后不会丢失。

### 校验

`verify_exported_data(..., export_by_l2=...)` 同步支持两种结构：

- 勾选时进入「二级分类」目录，再查找「图片ID」目录；
- 未勾选时按平铺目录查找；
- 仍然逐文件夹核对文件名与数量，缺失/多出都会报告。

## 三、二级分类快捷键修复

原实现的问题与处理：

| 问题 | 处理 |
| --- | --- |
| 中文输入法激活时 `e.key` 为 `Process` / `Unidentified` | 用 `e.code`（`KeyD`/`KeyF`…）兜底 |
| 分类名互相包含时可能点错（「衬衫」vs「衬衫长袖」） | 分类名精确匹配，快捷键标记 `[D]` 再兜底 |
| 再按一次已选中的分类会取消选择 | 已选中的 pill 不再重复点击 |
| Ctrl+D / Ctrl+F 等被拦截 | 有 Ctrl/Alt/Meta 时不处理 |
| 长按 D 反复切换 | `e.repeat` 时只处理第一次 |
| 找不到分类按钮时吞掉按键，空格/方向键也失效 | 找不到按钮时继续走其它快捷键 |
| rerun 后监听器可能拿到旧映射 | 映射写到父窗口全局，监听器实时读取最新值 |

备注：焦点在输入框 / 文本域 / 下拉框内时仍不触发字母快捷键，避免输入备注时误判。

## 六、已知限制

1. 导出目录仍按「前缀_合格数据_N组」命名；重复导出到同名目录会覆盖同名图片ID文件夹（原有行为）。
2. 二级分类名只做字符替换，不做长度截断；极端超长分类名可能受 Windows 路径长度限制。
3. 二级分类名相同的图片会进入同一个分类文件夹，这是预期行为。
4. 快捷键在备注输入框聚焦时不生效，需要先点一下页面空白处再按 D/F。
5. 极少数输入法在首次按键时可能闪一下候选框，但分类仍会被选中。
