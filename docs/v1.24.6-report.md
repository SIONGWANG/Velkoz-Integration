# v1.24.6 报告 — 读取规则面板改为标签页 + 单条编辑

- 日期：2026-11-26
- 分支：`1.24`
- 版本：`1.24.6`
- 基线：`v1.24.5`（`5904235`）

## 一、问题

v1.24.5 重做「自定义读取规则」后，内容虽然更清楚了，但所有文件夹块、图片槽位、文本框一次性铺开。当前配置有 7 个图片槽位、2 个文本框，展开后页面非常长，需要大量滚动。

## 二、改动

### 1. 三类配置改为标签页
- 顶部使用紧凑标签页：「命名 / 图片 / 文本」。
- 一次只展示当前标签页的配置，切换标签不触发整页重跑。
- 标签栏压缩内边距与字号，A 区窄栏下 3 个标签都能完整显示。

### 2. 多条配置只编辑当前项
- 文件夹块：有多个块时显示「块 1 / 块 2 ...」下拉，只渲染选中块的卡片。
- 图片槽位：有多个槽位时显示「槽位 1 / 槽位 2 ...」下拉，只渲染选中槽位的两个输入框与匹配示例。
- 文本框：有多个文本框时显示「文本框 1 / 文本框 2 ...」下拉，只渲染选中的一个。
- 增删后自动选中相邻项；排序只清理当前类型的 widget key，不会重置其他标签页的选择。

### 3. 其他压缩
- 移除顶部大说明卡，改为一行提示：「改完保存，再重新加载文件夹生效。」
- 正则表达式移入「🧪 测试匹配」折叠区，平时不占高度。
- 保留规则彩色块概览，仍能在不展开卡片的情况下看到整条文件夹规则。

### 4. 待定颜色
- A 区进度堆叠条、筛选按钮色点与选中态中的「待定」改为金黄色 `#f5c518`，与列表中的 🟡 保持一致。
- 选中时文字使用深色 `#4a2f00`，避免白字在金黄底上看不清。

### 5. 涉及文件
- `settings_mixin.py`
- `css_styles.py`
- `utils.py`（版本号）
- `CHANGELOG.md`
- `docs/v1.24.6-report.md`

## 三、效果

- 预览环境（3 个文件夹块、2 个图片槽位、2 个文本框）展开后，整页高度从约 4000px 降到约 850px。
- 实际配置（1 个文件夹块、7 个图片槽位、2 个文本框）图片标签页只显示 1 个槽位编辑器，不再平铺 7 个。
- 标签切换、下拉切换、编辑后重跑均保持当前标签页。

## 五、已知限制

1. 下拉只显示「块 1 / 槽位 1 / 文本框 1」，具体后缀和类型需在下方卡片查看；这样做是为了避免下拉文字被截断。
2. 文件夹块仍只提供精确长度输入；长度范围仅在已有配置包含 `min/max` 时保留。
3. 设置页仍位于「⚙️ 更多设置 → 🔍 自定义读取规则」折叠内。
