# v1.24.5 报告 — A 区进度面板重做 + 读取规则配置可视化

- 日期：2026-11-26
- 分支：`1.24`
- 版本：`1.24.5`
- 基线：`v1.24.4`（`78d4724`）

## 一、本次目标

1. 仿照用户提供的 `例子.html`，重做 A 区左上角进度显示，要求美观、简洁、实用，且不影响已有质检流程。
2. 重新排版设置页的「自定义读取规则」，让配置方式一眼能看懂，并适配 A 区窄栏。
3. 只调整展示与交互，不改变扫描规则解析、图片/文本匹配与保存格式。

## 二、改动内容

### 1. A 区进度面板（`zone_a.py`、`css_styles.py`）

- 顶部卡片显示「实时合格率 + 百分比」。
- 下方 5 段堆叠条，按数量占比展示：
  - 合格 `#22c55e`
  - 修改后合格 `#3b82f6`
  - 不合格 `#ef4444`
  - 待定 `#f59e0b`
  - 未检 `#cbd5e1`
- 堆叠条下显示「已检 X / 总数 · 进度 Z%」。
- 合格率口径收进卡片标题悬停提示，卡片正文只保留「不含未检 / 待定」，减少窄栏换行。
- 状态筛选改为 2×3 按钮：
  - 左侧色点 + 状态名 + 加粗数量。
  - 选中后整块填色、文字转白、色点隐藏。
  - 两列布局适配 A 区约 10% 的窄栏，避免「不合格」被拆成两行。
- 保留原 `filter_pills` 状态键，查询退出、筛选无数据等逻辑不变。

### 2. 自定义读取规则（`settings_mixin.py`、`css_styles.py`）

- 顶部新增说明卡：
  - 标题：读取规则：文件夹 → 图片 + 文本
  - 提示：改完保存，再重新「加载文件夹」生效。
- 文件夹命名规则：
  - 顶部用彩色块串联当前规则，例如「① 数字 0-9 8 位 + ② 固定字符「_」」，并显示生成的正则。
  - 每个块一张卡片：块编号 + 实时描述、字符类型下拉、长度/内容、可选标记。
  - 排序、删除改为窄栏友好的图标按钮；首块上移、末块下移、单块删除时按钮置灰。
  - 测试区保留「填入示例」与实时匹配结果。
- 图片槽位：
  - 每个槽位独立卡片，包含文件名后缀、扩展名过滤、删除按钮。
  - 输入后即时显示真实编号的匹配示例，例如 `00012345_result.png（扩展名：png）`。
- 文本槽位：
  - 每个文本框独立卡片，输入后显示 `00012345_ZH.txt` 示例。
- 保存 / 恢复默认改为全宽按钮，避免窄栏文字竖排。
- 匹配示例优先使用当前记录编号，其次当前批次第一条；无数据时用 `00012345`。

## 四、已知限制

1. A 区宽度由「横向占比」决定。默认 80% 时 A 区约 10% 宽，2×3 按钮可正常显示；若把横向占比调到 90%，A 区会更窄，按钮可能再次换行。
2. 文件夹块目前只提供「精确长度」输入；长度范围（min/max）只在已有配置包含范围时保留，本次未新增范围切换开关。
3. 设置页仍位于「⚙️ 更多设置 → 🔍 自定义读取规则」两层折叠内，没有独立的宽屏设置页；本次只优化内容布局。
4. 图片/文本匹配示例按当前编号拼接，实际文件名以扫描结果为准。
