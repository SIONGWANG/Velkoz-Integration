# v1.25.9 修复报告 —— 四宫格超过 4 张图片索引越界

> 版本：`1.25.9`
> 日期：2026-11-11
> 状态：已实现并完成本地验证，等待用户确认后提交
> 基线：`v1.25.8`（`2729d97`）

---

## 1. 问题

`zone_b.py` 的「四宫格」渲染只创建了 2 行 × 2 列共 4 个格子，但循环遍历全部图片：

```python
r1 = st.columns(2)
r2 = st.columns(2) if len(images) > 2 else []
for i, img in enumerate(images):
    tgt = r1[i] if i < 2 else r2[i - 2]
```

当批次有 5 张图片时，第 5 张图片访问 `r2[3]` 越界，页面直接报错。默认扫描规则允许主图、`_1`、`_2`、`_3`、`_result` 共 5 个槽位，因此这是正常数据会触发的错误。

## 2. 修复

改为按图片数量动态生成每行 2 张的布局：

```python
rows = [st.columns(2) for _ in range((len(images) + 1) // 2)]
for i, img in enumerate(images):
    tgt = rows[i // 2][i % 2]
```

- 1–4 张：保持原四宫格布局；
- 5 张及以上：继续向下排列；
- 不再假定最多 4 张图片；
- 图片加载、查看器、双击打开、快捷键和质检流程均未改变。
