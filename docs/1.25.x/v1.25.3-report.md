## 2. 关键行为

### 2.1 配对与状态

- 中文后缀默认 `_CH`、`_ZH`；英文后缀 `_EN`；大小写不敏感。
- 状态：缺少中文、缺少英文、英文为空、中文为空、已有英文、读取失败。
- 递归扫描会跳过符号链接/junction；支持最大任务数与重复任务 ID 提示。
- 扫描只读取目录项、文件大小和 TXT 内容，不写入、不重命名、不删除任何源文件。

### 2.2 翻译

- 三类提供方统一走 OpenAI 兼容 `chat/completions`：
  - Ark：`https://ark.cn-beijing.volces.com/api/v3`
  - 百炼：`https://dashscope.aliyuncs.com/compatible-mode/v1`
  - OpenAI 兼容：自定义 Base URL
- 支持超时、重试、并发、temperature、单价、计价单位和币种。
- 重试只针对可重试错误（限流、超时、连接失败、5xx）；认证失败和请求被拒绝直接返回。
- 支持停止；已完成的条目保留并入库。
- 翻译结果先写入管理数据目录 `reports/precheck_staging/<job_id>.json`，不进入数据库、不写源目录。

### 2.3 确认写入

- 只有用户点击“确认写入英文 TXT”后才写源目录。
- 目标英文 TXT 已存在且非空时默认拒绝覆盖，返回 `PC-201`；需显式勾选覆盖。
- 覆盖前复制到 `backups/precheck/<job_id>/<时间戳>/`，并校验源文件与备份哈希。
- 同目录临时文件 + `fsync` + `os.replace` 原子写入；写后读回校验。
- 路径必须位于任务根目录内，越界返回 `PC-202`。
- 换行风格尽量与中文 TXT 一致。

### 2.4 语法 / 一致性检查

- 模型返回 JSON 解析为 `passed`、`issues`、`suggestion`。
- 检查只写入管理数据库的建议字段，不自动修改英文 TXT。
- 用户确认建议后才写回，写回仍走备份、原子写入与覆盖保护。
- 无法解析的返回标记 `PC-303`，保留原始返回供人工判断。

### 2.5 API Key 与隐私

- 仅使用 Windows DPAPI（当前用户）加密；通过 `ctypes` 调用，不依赖 `pywin32`/`cryptography`。
- 文件：`<管理数据目录>/secrets/precheck_keys.json`，只保存密文、更新时间和掩码预览。
- 界面输入为密码框，已保存 Key 只显示掩码。
- 日志、报告、异常信息不包含明文 Key；请求异常文本会再做一次脱敏。
- 非 Windows 环境会明确提示不可用，不降级为明文保存。

### 2.6 费用与报告

- 费用按“输入 Token × 输入单价 / 单位 Token + 输出 Token × 输出单价 / 单位 Token”估算。
- Excel：总览、翻译明细、检查结果、费用、说明。
- CSV：`translation_report_*.csv`、`translation_checks_*.csv`、`cost_report_*.csv`，UTF-8 BOM。
- 翻译报告表头与外部工具一致；费用报告表头与外部工具一致。
- 报告只写入管理数据目录或用户指定目录；源目录内直接拒绝。

### 2.7 外部历史报告导入

- 支持 `translation_report_*.csv` 与 `cost_report.csv`。
- 表头按中文/英文别名映射；未知列忽略；未知状态保留为 `unknown:<原文>`。
- 翻译报告只有总 Token 时记入 `token_input`，`token_output` 为 0，总计仍正确。
- 行哈希去重；重复导入不会重复生成条目或费用记录。
- 只读取用户选择的 CSV，不修改外部工具目录与文件。

## 5. 已知限制与后续

1. 不保证与外部工具的 Prompt/质量完全一致；页面与报告均已明确提示。
2. 外部翻译报告通常只有总 Token，导入时无法拆分输入/输出，统一记入 `token_input`。
3. 导入的外部报告文本不写入数据库（数据库保持内容无关），历史详情中只保留索引与费用；如需保留原文，可后续在管理数据目录增加导入暂存。
4. 语法/一致性检查只产出建议；错误码与解析规则以当前 JSON 约定为准。
5. API Key 仅支持 Windows DPAPI；非 Windows 环境不可用，不会明文降级。
6. 当管理数据目录本身位于所选任务根目录内时，报告目录保护会拒绝写入该目录；这是有意的安全边界，可改到根目录外导出。
7. 打包问题仍按用户要求暂缓，不在本版本处理。
