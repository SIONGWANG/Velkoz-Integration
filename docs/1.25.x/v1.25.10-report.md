## 1. 本次要解决的问题

v1.25.8 的工作台虽然接入了待验/申请终验目录，但实际使用中仍有四个硬伤：

1. 批次列表把“格式检查 / 格式异常 / 翻译状态 / 验收状态”并排展示，信息过载，看不出“这一批现在该做什么”。
2. 管理中心 11 个页面平铺在侧边栏，扫描、格式、翻译、归档都像独立系统。
3. 从批次进入正式质检后还要手动点“加载文件夹”，等于路径仍然暴露在流程里。
4. 合格数据只能导出到源批次目录同级，想放进统一的库目录只能手工复制。

v1.25.10 按“一次配置、一个主按钮、路径不出现”的原则收敛。

## 2. 工作台重做

### 2.1 列表只保留一个主按钮

- 移除列表里的格式/翻译/验收状态列，改为一行事实 + 一个“下一步”按钮：
  - 未格式检查 → `开始格式检查`
  - 格式失败 → `处理格式异常`
  - 待翻译/部分完成/失败 → `继续翻译`
  - 待验收/进行中/无记录 → `开始验收`
  - 已验收未归档 → `导出与归档`
  - 已完成 → `查看详情`
- 批次卡片只显示：名称、批次号、日期、组数、图片数、验收进度、合格/不合格/剩余。
- 有格式失败、翻译失败、导入错误、归档冲突时，只显示一行“⚠️ 有异常，详情里可查看和处理”，不再铺开状态链。

### 2.2 按团队 / 类目分组

- 批次按团队分组，团队内按“大类目 / 小类目”分组。
- 顶部 4 个真实指标：待办批次、进行中、今日完成、异常批次。
- 筛选只保留：搜索、团队、类目、日期、只看未完成；范围切换为“全部 / 待验数据 / 申请终验”。
- 待确认新批次收进折叠区，仍要求人工确认，不按名称自动合并。
- 历史批次（未接入业务目录）单独折叠，不干扰当前工作。

### 2.3 批次详情瘦身

- 顶部只保留：开始验收（或下一步）、验收记录、进度。
- 主区域 3 个标签：`进度` / `验收记录` / `高级`。
- 格式检查、翻译、合格归档、来源关联、数据组、批次状态操作全部收进“高级”折叠区。
- 路径只放在“进度 → 来源目录与路径”折叠区，日常操作看不到。

## 3. 路径不再需要粘贴

- 从工作台或批次详情点“开始验收”，直接把该批次的 `batch_path` 写入正式质检数据源，并自动触发扫描加载。
- 首次加载会自动进入第一条数据组；不会清空已有质检记录（CSV 仍按原规则写回 `_质检记录`）。
- 工作台日常打开只读数据库；只有点“刷新待验 / 刷新终验 / 全部刷新”才访问网络目录。

## 4. 库目录导出

新增独立“库根目录”，在 `设置 → 输出库目录（合格数据）` 配置一次。

- 目录结构按批次相对业务根目录的层级镜像：
  - `库根\大类目\团队\1107\批次A`
- 已有层级目录直接使用；不存在则自动创建。
- 只复制，不移动、不删除、不改源目录。
- 默认不覆盖库中同名数据组：
  - 内容一致 → 跳过；
  - 内容不同 → 记为冲突，不覆盖；
  - 需要刷新时勾选“覆盖库中已存在的同名数据组”。
- 入口有两处：
  - 批次详情 → `📤 导出与完成本批`；
  - 正式质检 A 区 → `📚 导出到库目录（保持层级）`。
  两处默认都不覆盖：内容一致跳过，内容不同记为冲突；需要刷新时显式勾选“覆盖库中已存在的同名数据组”。
- 原有导出行为保持不变：
  - “一键导出合格数据”仍导出到源批次同级；
  - Excel 验收记录仍保存在 `_质检记录`。
- 合格数据来源：
  - 批次详情：按数据库 `imported_records` 中每个数据组的最新结果，取“合格 / 修改后合格”。
  - 正式质检：仍按当前 CSV 与当前已加载数据组。

## 5. 飞书摘要

飞书摘要 = 一段可直接粘贴到飞书表格的文本，**不联网、不需要密钥**。

- 工作台 → `📋 今日飞书摘要`：按今日批次生成“团队 · 类目 · 批次 | 合格/不合格 | 状态”。
- 批次详情 → `导出与完成本批` → 生成单批摘要。
- 同时提供“下载摘要 CSV”。
- `modules/feishu_summary.py` 预留 `FeishuAdapter.send(text)` 接口；以后接开放平台时只替换适配器，页面和统计逻辑不用改。

## 6. 导航收敛

侧边栏只保留 4 个主入口：


“批次总览 / 团队与类别 / 数据扫描 / 候选确认 / 格式检查 / 翻译预审 / 合格归档”收进“🧰 高级工具”折叠区，旧深链接和页面代码全部保留，不影响既有自动化与历史操作。

## 11. 已知限制

- 不内建解压：zip/rar/7z 仍需手动解压后刷新。
- 飞书只生成文本/CSV，不自动写入飞书；API 适配器仅预留接口。
- 批次详情的库目录导出依赖数据库中的导入记录；若验收结果只在质检 CSV 中、尚未导入，会提示“数据库暂无合格数据”，此时请到正式质检页导出。
- 工作台按团队/类目分组后仍是纵向列表，批次数特别多时页面会较长；当前未做分页。
- 库目录默认不覆盖，同名但内容不同的数据组需要人工确认后勾选覆盖。

## 12. 回滚

- 回滚到 `v1.25.9` 即可撤销本版本。
- 无数据库迁移，无需恢复数据库。
- 新增的 `library_root` 配置在回滚后不会被读取，保留无害。
- 回滚后合格数据导出恢复为“源批次同级”，已复制到库目录的数据不会被删除。
