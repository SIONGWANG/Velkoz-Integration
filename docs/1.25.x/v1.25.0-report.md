## 5. 只读与数据保护

本版本承诺：

1. 扫描/预览/保存扫描记录不写源图片、TXT、CSV；
2. 不删除、不移动、不重命名源文件；
3. 不跟随符号链接/junction；
4. 管理数据库只存路径、状态、规则、日志，不存原文；
5. 旧质检保存仍写回源 TXT（保持现状）；
6. 旧“不合格归集”仍复制后删除源目录（保持现状）；
7. 跨天记录仍按原逻辑写入旧 CSV（保持现状）。

## 6. 已知限制

1. 扫描当前为同步执行，UI 会等待扫描完成；已提供进度条与上限，后台任务/取消按钮留到后续版本。
2. 大量目录（> 20,000）或超大目录树需要提高上限或分批扫描。
3. 通用规则默认把所有组织层设为可选，只要求任务层；严格规则需要在 JSON 中把层设为 `required=true`。
4. 扫描记录保存后尚未提供“历史扫描详情/差异对比”页面，留到 v1.25.1。
5. 规则方案的图形化编辑未做；当前支持数据库方案选择、内置默认、JSON 导入。
6. 打包脚本未修改（按用户决定暂缓）。
