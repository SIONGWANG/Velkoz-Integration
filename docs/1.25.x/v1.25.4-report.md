新增迁移 `0005_record_import.sql`，schema 版本升至 5：

## 2. 关键行为

### 2.1 只读发现与类型识别

- 支持 `.csv`、`.xlsx`、`.xls`；旧版 `.xls` 明确标记“格式不支持”，不转换、不修改源文件。
- 识别工作记录 CSV、正式导出 CSV、统计/汇总表、备份表与无法识别表。
- 统计类文件只记录日志与状态，不生成逐条记录（`RI-014`）。
- 支持 UTF-8、UTF-8 BOM、GB18030/GBK、UTF-16；自动尝试 `,`、`;`、Tab 分隔符。
- `.xlsx` 使用 `zipfile` + XML 原生读取共享字符串与首个工作表，不依赖 `openpyxl`。
- 递归发现会跳过符号链接/junction；单层与递归都只读取文件信息与内容。

### 2.2 增量导入与去重

- 行指纹 = `sha256(规范化源路径 + 规范化整行原文)`。
- 同一文件重复导入不会重复生成记录；同一文件追加新行后再次导入只新增追加行。
- 支持试运行；试运行不创建导入日志、不写记录。

### 2.3 批次关联与原文保留

- 按图片ID/任务ID匹配 `data_groups`；可限定批次，也可自动关联到实际数据组所在批次。
- 无法匹配的任务保留为“未关联”；只有备注/标签、没有任务ID的行保留为“纯备注记录”。
- 未定义标签、错误截图/证据路径、备注、时间与路径均按原文保存；不要求本机存在同名标签，也不做自动映射。
- 显式指定的批次不存在时忽略并给出提示，不中断导入。

### 2.4 状态诚实

| 场景 | 发现页状态 | 导入日志状态 | 错误码 |
|---|---|---|---|
| 未发现文件 | 提示 | 不写日志 | `RI-001` |
| 表结构无法识别 | 结构无法识别 | 导入失败 | `RI-004` |
| 旧版 `.xls` | 格式不支持 | 导入失败 | `RI-005` |
| 统计/汇总表 | 可导入（类型：统计/汇总表） | 已导入（0 条记录） | `RI-014` |
| 行错误 | 可导入 | 部分/失败 | `RI-008` |
| 未匹配任务 | 可导入 | 已导入/部分导入 | `RI-012` |
| 重复行 | 可导入 | 已导入（跳过数） | `RI-009` |

## 5. 已知限制与后续

1. 旧版 `.xls` 暂不支持，需用户在 Excel 中另存为 `.xlsx`；不尝试转换或修改源文件。
2. 表头别名覆盖常见中英文列名；极端自定义表头可能被判为“结构无法识别”，可在后续版本扩展别名表。
3. 统计/汇总表只识别与记录，不解析统计数字；统计汇总留待 v1.25.7。
4. 同一 CSV 被复制到其他路径后会被视为独立来源；去重以“源路径 + 行原文”为准。
5. 记录明细只展示导入原文与关联状态，不替代现有质检 CSV 的权威地位。
6. 打包问题仍按用户要求暂缓，不在本版本处理。
