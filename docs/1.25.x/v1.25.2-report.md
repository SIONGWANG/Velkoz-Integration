### 2.3 检查与诊断

- 目录名必须整体匹配 ID 规则；不匹配的任务目录不会被误当成任务。
- 根目录本身像任务目录但名称不符合规则时输出 `FC-001`。
- 文件名 ID 与目录 ID 不一致输出 `FC-003`。
- 单图扩展名冲突 `FC-108`，主图/结果图扩展名不符 `FC-106/FC-107`。
- 多图数量、连续性、重复编号、起始编号、扩展名、格式分别输出 `FC-201`～`FC-207`。
- 双模式先分别计算通过条件；都未通过时先按“识别到哪种结构”选择模式，再按问题数量选择，避免多图任务被误判为“缺主图”。
- 额外文件按模板策略输出 `FC-301`；系统临时文件输出 `FC-306`。
- 0 字节文件、未来时间、隐藏文件、大小写冲突、全角/空格分别输出 `FC-302/308/309/307/303`。
- 目录不可读输出 `FC-006`；任务读取异常输出 `FC-304`。

### 2.4 只读保证

- 检查前后对每个任务目录做轻量快照（相对名 + 大小 + `mtime_ns`）；
- 快照变化时追加 `FC-311`，`integrity_status=warning`，并在页面与报告显著提示；
- 不跟随符号链接/junction；
- 报告目录位于检查源目录内时直接拒绝，检查不会开始；
- 检查过程不写 `.json`/`.log`/`.tmp`/缓存到源目录；
- 报告只写入管理数据目录 `reports/format_check/` 或用户指定目录。

### 2.5 模板管理

- 内置模板 `builtin_default` 只读；
- 自定义模板支持新建、复制、导入 JSON、导出 JSON、保存为新版本、删除；
- 每次保存生成 `format_template_versions` 新版本；
- 检查记录保存模板快照，后续修改模板不影响历史结果；
- 模板作用域字段（global/supplier/team/category/project）已入库；v1.25.2 由用户手工选择模板，按作用域自动匹配留待后续版本。

### 2.6 报告

- 总览：运行信息、模板、耗时、数量、完整性、错误码汇总；
- 任务结果：ID、路径、模式、结果、图片数、TXT 数、文件数、问题数、指纹；
- 异常明细：错误码、级别、文件、期望、实际、说明、建议；
- 规则说明：模板快照、规则解释、只读声明；
- 差异：与上次运行对比时生成。

CSV：

- `format_check_tasks_*.csv`

- UTF-8 BOM，列名固定。

## 6. 已知限制与边界

1. **未实现的可选错误码**：`FC-005`（目录层级）、`FC-305`（TXT 内容/编码）、`FC-310`（读取图片文件头判断真实格式）。这些在设计中标注为“可选”，v1.25.2 不启用，避免误报和额外读盘。
2. **模板作用域自动匹配未启用**：字段已保存，页面目前手工选择模板；按供应商/团队/类目自动选择留待后续版本。
3. **多图扩展名不当**：多图编号文件扩展名不在白名单时输出 `FC-206`；但若任务没有任何合法多图文件，可能优先显示单图缺主图，这是双模式“选择更接近通过模式”的预期行为。
4. **UI 停止**：通过取消令牌在任务之间停止；正在读取的单个任务会先完成。已检查结果会保留并入报告。
5. **未做真实 10,000 任务压测**：本地目标 < 60 秒需要在用户真实目录验证。
6. **不检查图片质量/PSD 图层/语义**：按设计明确不做。
7. **打包问题仍暂缓**：本版本未处理 PyInstaller/打包配置。
