## 关键结论

1. **现有质检核心可以保留，不需要推倒重写。** 当前是 Streamlit 单页 + 6 个 Mixin + CSV/文件夹持久化；图片查看器、快捷键、截图、查询、导出链路完整，v1.24.0 刚完成锁定视图与大图异步加载。
2. **格式检测应原生重写，而不是调用 `图片编辑工具箱.exe`。**
   - 外部工具没有源码、没有公开 CLI、没有外部规则文件；模板与规则在 EXE 内部。
   - 它的核心检测规则已被使用说明完整描述，足以用纯 Python 只读实现。
   - 原生实现可以复用现有扫描规则、批次身份、验收记录和 Excel 导出能力。
   - 只做“格式检测”，不做人物一致性、分组整理、压缩、水印等其他功能。
3. **豆包 AI 预审工具按“原生仿照 + 历史报告导入”设计。**
   - 原生实现翻译、模型配置、语法检查、中英文一致性检查、智能修正建议、Token/费用统计和报告。
   - 原工具只有 EXE、没有源码/Prompt，因此**不能承诺与其 Prompt/质量完全等价**。
   - 保留只读导入其 `translation_report_*.csv` / `cost_report.csv`，用于历史记录与费用迁移。
   - 不读取/复制其 API Key，不调用未公开的内部接口。
4. **数据库只做索引与元信息，不做原始数据仓库。** 默认 SQLite 放在用户本地数据目录，图片/TXT 仍在原文件系统。
5. **旧版兼容的第一原则：CSV 仍是现有质检的权威记录。** v1.25.x 期间数据库是“派生索引”，不取代 CSV；其他验收员继续用旧版不受影响。
6. **三个数据安全行为已确认保持现状**（见 `00-decisions.md` D-002），不再作为阻塞项：
   - 现有 `save_to_disk()` 仍写回源目录 TXT；
   - 现有“不合格归集”仍复制后删除源目录；
   - 现有跨天 CSV 回退仍会把新记录写进旧文件。
   - 新增模块不得改变这些默认行为，只记录操作日志；未来如加保护，只做可选开关。
