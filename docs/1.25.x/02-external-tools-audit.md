## 1. 结论先行

| 工具 | 可复用方式 | 不能做的事 | 建议 |
|---|---|---|---|
| 豆包 AI 预审工具 v3.6 | **原生仿照核心功能**（翻译/语法/一致性/费用/报告）+ 只读导入其历史报告 | 不能 `import` 原 EXE；不能保证与其 Prompt/质量完全等价；不能读取/复制其 API Key；不能依赖未公开的内部 HTTP API | v1.25.3 在 `modules/precheck/` 原生实现；保留外部报告导入 |
| 图片编辑工具箱 v0.7.2 | **只复用“格式检测”规则与产品行为**，用纯 Python 原生重写 | 不能把整个 EXE 嵌入 Streamlit；不能反编译；不能把其 Qt/PIL 运行时当依赖 | v1.25.2 原生实现格式检测模块；其余功能不做 |

核心判断：

> **格式检测是“规则 + 文件系统读取”，不是“调用一个黑盒”。**
> 使用说明已经把默认规则描述完整，原生实现比进程封装更可控、更可测试、更能与现有批次/规则/报告整合。
> **AI 预审是“模型调用 + TXT 生成 + 记账”，也可以原生实现。**
> 但没有原工具源码/Prompt，**不能声称翻译质量与原工具完全一致**；原生模块使用自己的 Prompt，并允许用户编辑/对比；原工具的历史报告只读导入，用于费用与记录迁移。

### 2.5 融合方案（已确认：原生仿照 + 历史报告导入）

#### 方案 A：原生 `modules/precheck/`（推荐并已采用）

```text
审视之眼扫描批次
  → 识别中文/英文 TXT 配对与状态
  → 选择模型/并发/超时/重试
  → 批量或单条翻译（调用 Ark / 千问 / OpenAI 兼容）
  → 翻译结果预览
  → 用户确认后写英文 TXT（写前备份、原子写入、失败不覆盖）
  → 英文语法检查
  → 中英文一致性检查
  → 智能修正建议（确认后才写）
  → Token/费用账本
  → 翻译报告（Excel/CSV）
```

模块结构：

```text
modules/precheck/
├── models.py
├── pairing.py          # _CH/_EN 配对、缺失/已翻译状态
├── providers/
│   ├── base.py         # 统一 chat/translate 接口
│   ├── ark.py          # 豆包 Ark（OpenAI 兼容）
│   ├── dashscope.py    # 阿里云百炼/千问兼容模式
│   └── openai_compat.py
├── prompts.py          # 翻译/语法/一致性 Prompt（可编辑、可恢复默认）
├── service.py          # 批量、并发、重试、取消、进度
├── safety.py           # 备份、原子写、失败不覆盖
├── cost.py             # Token/费用、单价配置
├── report.py           # Excel/CSV
├── secrets.py          # DPAPI 加密
└── ui.py               # 翻译与预审页面
```

明确限制：

- **没有原工具源码/Prompt**，不能保证翻译质量、断句、术语与原工具完全一致；

### 3.2 使用说明中的格式检测规则

来自 `产品介绍与使用说明.txt`：

1. 粘贴路径或选择项目文件夹。
2. 选择已保存的命名模板；可在“管理模板”中另存为自定义模板，再勾选单图、多图中的一种或两种。
3. 默认检查所选目录及其直接子文件夹；勾选“递归扫描”后检查全部层级。
4. 点击“开始检测”。结果表可滚动、搜索并打开任务文件夹；结束或中途停止后自动生成 Excel，可在日志中心打开。
5. 单图默认允许：
   - `任务ID.jpg/jpeg/png`
   - `任务ID_result.jpg/jpeg/png`
   - `任务ID.psd`
   - `任务ID_CH.txt`
   - `任务ID_EN.txt`
   - 文件尾缀、扩展名和必需文件可在命名模板中切换。
6. 多图默认允许 `任务ID_1`～`_4.jpg/jpeg/png`；自定义模板可设置最大数量或“不限制”；编号是否连续由模板决定。
7. 任务 ID 只允许“指定位数纯数字”或“JD + 指定位数数字”。
8. **文件夹与所有业务文件的任务 ID 必须一致。**
9. 格式检测只检查目录结构/命名，不检查图片质量、PSD 图层、语义内容。

## 5. 风险与未验证项

1. **格式工具的真实边界未黑盒验证**：例如 `ID.JPG` 大小写、`ID_result.PSD`、`ID_0`、隐藏文件、Thumbs.db、子目录中的子目录。原生实现必须用模板显式定义，并在报告中列出“按本平台规则”的说明。
2. **格式工具是否会自动写文件**：使用说明只描述检测/报告；本次未运行工具，不能证明。原生实现强制只读。
3. **AI 工具的内部接口**：除 `/health` 外未验证；不得假设。
4. **AI 工具的 Key 存放**：未读取；本平台不接管。
5. **AI 工具报告是否覆盖失败重试/增量**：表头有“状态”，但语义需在 v1.25.3 用样本验证；导入器必须容忍未知状态值。
6. **工具版本升级**：外部工具升级后报告列可能变化；导入器必须做列映射与版本探测。
