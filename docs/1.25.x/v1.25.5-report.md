## 1. 交付范围

### 1.1 管理中心导航

- 管理平台从“更多设置”中的平级按钮独立出来，主界面顶部新增“🧭 管理中心”入口。
- 旧“更多设置 → 1.25 管理平台”入口已移除。
- 管理中心使用左侧导航，默认进入“批次总览”；保留“← 返回正式质检”。
- 默认正式质检三栏布局不变。

导航结构：

```text
管理中心
├── 📦 批次总览（默认）
├── 🏠 工作台

├── 📂 数据扫描

├── 🔎 格式检查

├── 📥 记录导入
```

### 1.2 批次总览

- 以批次为单位展示，不默认展开到单条记录。
- 常驻筛选：**团队、供应商、日期、一级类别、二级类别**；另有批次状态与关键词。
- 批次表格字段：批次号、批次名、团队、供应商、日期、一级/二级、任务数、合格、不合格、剩余、导入记录、格式、翻译、验收、状态、最近活动。
- 支持在表格中选择一行打开批次详情，也保留下拉框打开方式。
- 合格/不合格/剩余优先取批次验收统计；未同步时显示 0，并在页面明确说明，不虚构进度。

### 1.3 工作台

- 总览指标：批次数、任务数、待处理批次、异常批次、导入记录。
- 四个页签：今日批次、待处理、异常提醒、最近动态。
- 异常提醒基于格式检查失败与导入错误，不推测其他验收员实时状态。
- 最近动态显示最近导入与最近格式检查。

### 1.4 团队与类别

- “按团队”：批次数、任务数、合格/不合格/剩余、导入记录、格式失败、翻译任务、品类与最近活动；附任务数柱状图。
- “按类别”：按一级/二级类别汇总批次数、涉及团队、任务数、合格/不合格/剩余、导入记录与格式失败；附任务数柱状图。
- 支持团队、日期与关键词筛选。

### 1.5 批次详情

- 头部：批次名、批次号、团队、类别、日期、状态、验收/格式/翻译状态。
- 指标：任务数、合格、不合格、剩余、导入记录。
- 概览：数据根目录、批次目录、供应商/项目、最近活动、提交身份原文、子批次、状态记录。
- 明细页签：数据组、导入记录、格式检查、翻译预审。
- 状态操作：暂停、重开、标记完成、归档；写入 `batch_status_log` 与 `operation_logs`。
- 所有明细只显示索引与统计，不加载图片。

## 2. 关键行为

### 2.1 批次状态

- 支持状态：`confirmed`、`paused`、`completed`、`archived`。
- 暂停/重开/完成/归档只更新 `batches.status`、写入 `batch_status_log` 与 `operation_logs`。
- 不移动、不删除、不修改任何任务、图片、TXT 或 CSV。
- 状态更新要求操作员非空并在界面勾选确认。

### 2.2 数据来源与诚实状态

| 指标 | 来源 |
|---|---|
| 任务数 | `data_groups` |
| 合格/不合格/剩余 | `batches.qualified_count` / `rejected_count` / `remaining_count` |
| 导入记录 | `record_imports`（按 batch_id） |
| 格式状态 | `format_check_runs`（按 batch_id） |
| 翻译状态 | `translation_jobs`（按 batch_id） |
| 团队/供应商/项目 | `batches.identity_json`，缺失时回退 `team_id` / `supplier_id` / `project_id` 或数据组验收员 |

未同步的验收统计显示 0，并在页面注明，不生成虚假进度。

### 2.3 默认行为保持

- 主界面正式质检三栏布局、快捷键、查看器、记录、快速查询、导出、标注、截图、Excel 导入、局域网路径均未改变。
- 原有 CSV/TXT 写入、归集删除源目录、跨天 CSV 回退行为未改变。
- 管理中心的查询不写数据库；只有批次状态操作写管理数据库。
