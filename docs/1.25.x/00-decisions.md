## D-003 豆包 AI 预审工具：原生仿照 + 历史报告导入

- **决定**：在 `modules/precheck/` 中原生实现豆包 AI 预审工具的核心能力，不再只做外部进程封装。
- **原生范围**：

  - 中文/英文 TXT 配对识别；
  - 批量/单条翻译；
  - 豆包 Ark、阿里云百炼/千问、OpenAI 兼容接口；
  - 模型配置、测试连接、超时、并发、重试；
  - API Key 使用 Windows DPAPI 加密保存；
  - 英文语法检查；
  - 中英文一致性检查；
  - 智能修正建议（确认后才写）；
  - Token/费用统计；
  - 翻译报告（Excel/CSV）；
  - 失败重试、跳过已翻译、指定重新翻译；
  - 写前备份、失败不覆盖有效英文、原子写入。

- **明确不能保证**：

  - 与原工具**完全相同的 Prompt 和翻译质量**；
  - 与原工具内部实现等价；
  - 不读取、不复制原工具的 API Key。

- **兼容入口**：

  - 保留只读导入 `translation_report_*.csv` / `cost_report.csv`，用于历史记录与费用迁移；
  - 不修改原工具目录与文件。
