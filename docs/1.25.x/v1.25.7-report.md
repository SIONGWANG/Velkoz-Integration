## 1. 交付范围

### 1.1 管理中心新增“数据统计”

管理中心左侧导航新增：

```text
📊 数据统计
```

页面默认顺序为：筛选条 → 总览与批次 → 人员统计 → 错误与标签 → 日报 → 可追溯明细 → Excel 导出。不改变正式质检三栏布局，默认入口仍为“批次总览”。

### 1.2 常驻筛选

| 筛选项 | 说明 |
|---|---|
| 日期范围 | 全部 / 今天 / 最近 7 天 / 最近 30 天 / 本月 / 自定义（`YYYY-MM-DD`） |
| 批次 | 全部或指定批次 |
| 团队 | 来自 `data_groups.user_name` 与批次 `identity_json.team` |
| 人员 | 来自 `imported_records.operator` |

日期、批次、团队、人员四个筛选在页面顶部常驻；批次统计严格按批次展示，不按单条记录展开。

### 1.3 统计内容

| 模块 | 内容 |
|---|---|
| 总览 | 批次数、任务数、图片数、格式检查/失败、翻译完成/失败、导入验收、批次快照、归档 |
| 批次统计 | 批次号、名称、团队、供应商、日期、一级/二级、状态、任务、图片、格式、翻译、批次合格/不合格/剩余、导入验收、归档、最近活动 |
| 人员统计 | 按人员 × 日期 × 批次：验收记录、合格、不合格、其他、合格率、涉及任务、图片数、工作量；另提供按人员汇总 |
| 工作量 | 按验收记录数 / 按图片数 / 记录数 + 图片数×0.05 三种口径 |
| 错误类型 | 错误码、说明、级别、次数、涉及任务/批次、首次/最近时间 |
| 标签统计 | 标签原文、次数、涉及批次/人员、合格/不合格 |
| 日报 | 新增批次/数据组、格式检查/失败/警告、翻译、验收/合格/不合格、归档、剩余 |
| 可追溯明细 | 验收明细（来源文件、来源行）与格式错误明细（批次、任务、文件、期望/实际）分页查看 |

### 1.4 统计口径

| 指标 | 来源 | 说明 |
|---|---|---|
| 批次/任务数 | `batches` / `data_groups` | 批次与数据组索引 |
| 图片数 | `data_groups.image_count` | 扫描时记录；未扫描可能为 0 |
| 格式检查 | 批次最近一次 `format_check_runs` | 批次统计不使用被后续 run 覆盖的旧结果 |
| 格式错误 | `format_check_issues.code/severity` | 说明取 `ERROR_CATALOG`；未知错误码回退为错误码本身 |
| 翻译 | 批次最近一次 `translation_jobs` + `translation_items` | `translated` / `failed` 分列 |
| 验收/合格/不合格 | `imported_records.result` | 合格含“合格/修改后合格”；不合格含“不合格/作废”；其他结果单列 |
| 批次合格/不合格/剩余 | `batches.qualified_count/rejected_count/remaining_count` | 批次统计快照；未同步显示 0 |
| 归档 | `archive_items.status in ('verified','skipped')` | 只统计已校验或已存在跳过的数据组 |
| 标签 | `imported_records.tags_raw` | 保留历史原文，未定义标签也统计 |
| 日报 | 上述源表按事件日期归集 | 日期由页面显式指定，不再叠加日期范围筛选 |

> 批次统计的日期筛选作用于批次提交日期；批次内任务/图片/格式/翻译/快照/导入验收按该批次完整口径统计。人员、标签、错误明细的日期筛选作用于事件日期。

### 1.5 可追溯与大数据量

- 验收明细返回 `record_id`、来源文件 `source_path`、来源行 `source_row`、任务、批次、数据组、标签与备注。
- 格式错误明细返回批次、任务、任务路径、文件、期望/实际、说明与检查时间。
- 两类明细均提供总数、分页查询和批量迭代（`iter_imported_records` / `iter_format_issues`），避免一次性加载全部数据。
- Excel 明细最多导出 5000 条，并在工作表中注明总数与提示在页面分页查看。

### 1.6 Excel 导出

工作表固定为：

```text
筛选与总览 / 批次统计 / 人员统计 / 错误类型 / 标签统计 / 日报 / 口径说明 / 验收明细 / 格式错误明细
```

- 使用 `xlsxwriter`（当前环境未安装 `openpyxl`）。
- 导出写入管理数据目录 `reports/stats`，文件名 `stats_YYYYMMDD_HHMMSS.xlsx`。
- 页面生成后可下载；源图片/TXT/CSV 不访问、不修改。

## 2. 数据库

### 2.1 迁移 `0007_stats.sql`

新增 `stats_daily`：

| 列 | 说明 |
|---|---|
| `id` | 主键 |
| `date` | 日期 |
| `batch_id` / `operator` | 可空作用域 |
| `new_batches` / `new_groups` | 新增 |

| `archived` / `pending` | 归档与剩余 |

- `idx_stats_daily_scope`：`(date, COALESCE(batch_id,''), COALESCE(operator,''))` 唯一；

`stats_daily` 是可按源表重建的缓存，不保存图片/TXT/CSV 原文。重建时先删除同范围缓存再写入，重复重建不会产生重复行。

## 5. 已知限制与后续

1. 统计只覆盖已进入管理数据库的数据；未导入的验收记录显示 0，不做推算。需要时先执行“记录导入”。
2. 批次统计的格式/翻译取最近一次 run/job；历史多次运行的逐次对比未在统计页展开。
3. 工作量权重目前提供三种固定口径，暂未提供可视化自定义权重。
4. 标签按常见分隔符拆分，保留原文；极端自定义分隔符可能作为一个标签统计。
5. Excel 明细最多 5000 条；完整明细请在页面分页查看或分批导出。
6. 日报缓存当前按“全部作用域”（`batch_id`/`operator` 为空）写入；按批次/人员缓存列已预留，后续可按需扩展。
7. 打包问题仍按用户要求暂缓。
