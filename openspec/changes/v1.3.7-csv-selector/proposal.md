# CSV 历史文件选择器

## 问题描述

CSV 文件名包含当天日期（如 `新标_张三_20260530_验收记录.csv`），`get_csv_filename()` 始终按当天日期生成路径。跨天后旧数据不可见，用户需要改系统时间才能查看历史数据，严重影响复核工作。

## 优化方案

在侧边栏"加载文件夹"按钮之后，添加一个 CSV 文件选择器下拉框：

1. 扫描 `_质检记录/{operator}/` 下所有 `*_验收记录.csv` 文件
2. 按日期倒序列出，选项为"今天（自动）"+ 历史文件名
3. 选择后覆盖 `get_csv_filename()` 的返回值，全局生效

## 设计要点

- `get_csv_filename()` 是所有模块的唯一 CSV 路径来源，改它一处即全局生效
- 用 `st.session_state.selected_csv` 作为覆盖值，`None` 表示走默认日期逻辑
- 缓存机制天然兼容：缓存 key 包含文件路径，切换文件自动失效

## 影响范围

- `data_mixin.py` — 新增扫描方法、修改路径生成、重置状态
- `settings_mixin.py` — 添加选择器 UI
