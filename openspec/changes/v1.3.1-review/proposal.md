# V1.3.1 需求提案

## 背景

V1.3.0 的输出文件命名存在不一致问题：
- CSV 和 Excel 命名风格不同
- 合格导出和不合格归集命名风格不同
- 无法区分"新标"和"返修"任务类型

用户需要在启动时选择任务类型（新标/返修），所有输出文件名自动包含该标签，便于归档和追溯。

## 需求清单

### 1. 启动界面新增任务类型选择

- 新增"任务类型"单选按钮：`新标` / `返修`（必选）
- 操作员姓名改为必填
- 选择结果存入 `session_state`

### 2. 统一命名规范

| 输出类型 | 命名格式 | 存放位置 |
|---------|---------|---------|
| CSV | `{标签}_{操作员}_{日期}_验收记录.csv` | `{根路径}/_质检记录/{操作员}/` |
| Excel | `{标签}_{操作员}_{日期}_验收记录.xlsx` | `{根路径}/_质检记录/{操作员}/` |
| 合格导出 | `{标签}_{操作员}_{日期}_合格数据_{数量}组/` | `{根路径}/` 的父目录 |
| 不合格归集 | `{标签}_{操作员}_{日期}_不合格_{数量}组/` | 不合格记录的父目录 |
| 截图证据 | `_00_Evidence_{标签}/` | `{根路径}/` |

### 3. 变量说明

| 变量 | 来源 | 格式 |
|-----|------|------|
| `{标签}` | 启动时全局选择 | `新标` / `返修` |
| `{操作员}` | 启动时输入 | 用户姓名（必填） |
| `{日期}` | 自动生成 | `YYYYMMDD` |
| `{数量}` | 自动统计 | 数字 |

## 示例

根路径 `D:/项目A`，操作员张三，新标：

```
D:/项目A/_质检记录/张三/
├── 新标_张三_20260526_验收记录.csv
└── 新标_张三_20260526_验收记录.xlsx

D:/项目A/_00_Evidence_新标/
├── 00000001_1716700200_0.png
└── 00000002_1716700201_0.png

D:/新标_张三_20260526_合格数据_15组/

D:/新标_张三_20260526_不合格_3组/
```
