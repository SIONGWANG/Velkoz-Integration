审视之眼 Pro 是一款专为视觉内容质检设计的桌面工具，支持智能扫描、四宫格审核、 L1/L2 分类、错误截图标记、快捷标签和一键导出等全流程功能，让质检工作高效且可追溯。

核心功能

六大能力，覆盖质检全流程

智能扫描

自动遍历嵌套目录，智能识别图片组和文本文件，支持可配置的扫描规则。

四宫格审核

同时展示多张关联图片，一屏完成对比审核，大幅提升效率。

L1/L2 分类

双层级缺陷分类体系，精确区分严重程度，支持自定义分类配置。

错误截图

一键截取缺陷区域，自动保存为证据图片，支持标注和备注。

快捷标签

预设常用缺陷标签，点击即填，支持自定义标签库和快捷键操作。

一键导出

自动生成质检报告，支持 CSV/Excel 格式，数据完整可追溯。

三栏布局设计

高效协作的界面架构 · 每个区域都有丰富的功能

A 区 导航列表

数据总览与智能筛选中心

📊 实时统计仪表盘

  • ✓ 6 维数据统计：合格 / 不合格 / 修改后合格 / 待定 / 未检，实时计算合格率
  • ✓ 进度条可视化：显示已完成/总数百分比，一目了然当前验收进度
  • ✓ 动态更新：每次提交后自动刷新统计，无需手动刷新

🔍 智能筛选系统

  • ✓ 6 维筛选按钮：全部 / 未检 / 合格 / 不合格 / 修改后合格 / 待定
  • ✓ 筛选联动：切换筛选后自动跳转到对应列表首条，B/C 区同步更新
  • ✓ 空状态提示：筛选结果为空时友好提示，引导切换条件

📋 图片组列表

  • ✓ 状态标识：🟢合格 🔴不合格 🔵修改后合格 🟡待定 ⚪未检
  • ✓ 标注员显示：每条记录显示标注员姓名，超长自动截断
  • ✓ 分页加载：每页 20 条，支持翻页，大数据量不卡顿 性能优化
  • ✓ 自动滚动：选中项自动滚动到可视区域，减少手动操作
  • ✓ 快捷键导航：上一条/下一条快速切换，跟随筛选条件

C 区 详情面板

审核操作与数据管理中心

ℹ️ 数据信息

  • ✓ 标注员信息：显示当前数据所属标注员姓名
  • ✓ 数据 ID：唯一标识，便于追溯和定位
  • ✓ 快捷操作：一键打开文件夹 / 打开原图，系统级调用

📷 错误截图池

  • ✓ 最多 3 张：支持粘贴 (Ctrl+V) 截图，实时预览
  • ✓ 一键清空：快速清除所有截图，重新开始
  • ✓ 导出集成：截图自动嵌入 Excel 报表，无需手动整理

🏷️ L1/L2 分类 + 状态判定

  • ✓ 双层级分类：L1 一级目录 + L2 二级目录，Pills 样式选择
  • ✓ 记忆功能：L1 选择后自动保留，切换数据不丢失
  • ✓ 4 种状态：合格 / 不合格 / 修改后合格 / 待定
  • ✓ 智能校验：合格/修改后合格必须填写 L1/L2，否则拦截提交 数据安全

💬 备注 + 标签系统

  • ✓ 备注输入：自由文本，支持手动编辑和标签自动同步
  • ✓ 快捷标签：常用标签 + 全部标签，Pills 多选，点击即填
  • ✓ 标签管理：新增 / 删除 / 全选 / 清空，持久化存储
  • ✓ 保存/提交：仅保存 或 提交并跳转下一条，支持抽检模式
