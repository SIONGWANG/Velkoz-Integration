审视之眼 Pro

图像质检验收工具 · 用户操作手册 · 版本 1.3.0

产品概述

审视之眼 Pro 是一款面向图像标注团队的 Web 端质检验收工具。质检员可以通过它逐条审核标注数据、判定合格/不合格、附加错误截图、管理分类标签，并一键导出合格数据与 Excel 质检报告。

数据扫描
自动遍历目录，识别数字文件夹作为质检项，支持可配置扫描规则
可视化审核
四宫格 / 单图对比双模式，支持中英文文本编辑
结构化判定
L1/L2 分类、快捷标签、备注、错误截图，数据完整落盘
一键导出
合格数据复制、不合格归集、Excel 报告（含嵌入截图）

启动与环境

环境要求

  • Python 3.11（推荐通过官方安装器安装，并勾选 "Add to PATH"）
  • 依赖包：streamlit pandas Pillow XlsxWriter streamlit-paste-button

启动步骤

  1. 双击运行项目根目录下的 启动_采集质检版.bat
  2. 脚本自动检测 Python 环境并安装缺失依赖
  3. 自动寻找可用端口（从 8502 起），启动 Streamlit 服务
  4. 浏览器自动打开 http://localhost:{port}，看到主界面即启动成功
提示
如果浏览器未自动打开，手动访问终端中显示的 URL 即可。默认端口 8502，若被占用会自动递增。

标准工作流

以下是一次完整质检验收的标准操作流程：

  1. 启动应用 — 双击 启动_采集质检版.bat，等待浏览器打开
  2. 填写基本信息 — 在 A 区输入质检员姓名、粘贴任务根目录路径
  3. 加载数据 — 点击「加载文件夹」，等待扫描完成
  4. （可选）确认标注员 — 若开启多标注员模式，检查并确认标注员名单
  5. 逐条审核 — 在 A 区列表点击 ID，B 区查看图片与文本，C 区选择分类和判定结果
  6. 附加证据 — 对不合格项，Ctrl+V 粘贴错误截图（最多 3 张）
  7. 保存/提交 — 点击「保存」仅记录，或「提交并下一条」自动跳转
  8. 全部完成后导出 — 使用 A 区导出面板，导出合格数据、归集不合格数据、生成 Excel 报告

A 区 · 左侧面板

A 区是控制中心，包含状态监控、数据筛选和导出管理。

状态仪表盘

实时显示各项统计数据：

合格
标记为「合格」的数据条数
修改合格
经过修改后判定合格的条数
不合格
判定不合格的条数
待定
需要进一步确认的条数

同时显示通过率百分比和进度条，直观反映质检完成度。

状态筛选

提供 2×3 网格的筛选按钮，可按状态过滤 ID 列表：

  • 全部 — 显示所有数据项
  • 未审核 — 尚未做出判定的项
  • 合格 — 已判定合格
  • 修改合格 — 修改后合格
  • 不合格 — 判定不合格
  • 待定 — 待进一步确认

ID 列表

分页显示所有质检项（每页 20 条），每条显示：

  • 带颜色的状态标识（绿/蓝/红/黄/灰）
  • 数据 ID 编号
  • 标注员姓名

点击任意 ID 即可在 B 区加载对应图片进行审核。

导出管理面板

位于 A 区底部，包含以下操作按钮：

  • 导出合格数据 — 将合格/修改合格项的文件夹复制到时间戳输出目录
  • 归集不合格数据 — 将不合格/待定项移至 {日期}不合格 文件夹
  • 导出 Excel 报告 — 生成含嵌入截图的 .xlsx 质检报告
  • 导出校验 — 逐文件对比源与目标，确认数据完整性
安全机制
导出前系统会自动检查：所有已加载的数据 ID 是否都有对应的 CSV 记录。若有遗漏，导出将被阻止，并列出缺失的 ID。

抽样验收

可按 5%~50% 的比例随机抽取数据进行重点审核。抽样模式下仅显示被抽中的项，退出抽样后自动恢复完整列表。

设置面板

可调整以下参数：

  • 布局宽度 — 中间 B 区宽度比例（50%~90%）
  • 布局高度 — 图片显示区域高度比例（60%~95%）
  • 视图模式 — 四宫格 / 单图对比
  • 扫描规则 — 在线编辑文件夹位数、图片槽位、文本槽位
  • 快捷键开关 — 启用/禁用键盘快捷键

B 区 · 图片展示区

B 区是核心审核区域，占据界面中央最大空间。

视图模式

四宫格模式

以 2×2 网格同时展示所有图片（原图、结果图等）。双击任意图片可在系统默认查看器中打开大图。

单图对比模式

每次显示一张图片，通过标签页按钮切换（原图 / 结果图 / 遮罩图等）。适合需要仔细对比细节的场景。

进度指示器

顶部显示当前位置 / 总数，配合迷你进度条，方便了解审核进度。

文本区域

图片下方显示并允许编辑中英文指令文本文件：

  • 中文文本（_ZH / _CH 后缀文件）
  • 英文文本（_EN 后缀文件）

AI 质检结果

若已加载 AI 报告，B 区会额外显示 AI 的判定结果、原因分析和完整 JSON 数据，供质检员参考。

批次完成面板

当所有数据项审核完毕，B 区自动切换为完成面板，显示汇总统计、通过率，以及导出 Excel 和归集不合格数据的快捷按钮。

C 区 · 右侧操作区

C 区是操作面板，完成每条数据的判定和保存。

数据项信息

  • 当前标注员姓名
  • 当前数据 ID
  • 「打开文件夹」按钮 — 在资源管理器中打开
  • 「打开原图」按钮 — 在系统查看器中打开

错误截图

每条数据最多附加 3 张 错误截图，支持两种方式：

  • 粘贴 — 截图后按 Ctrl+V 粘贴
  • 上传 — 点击上传按钮选择本地图片

截图以缩略图形式展示，点击可预览。

L1/L2 分类

两级层级分类选择器，以药丸按钮形式展示。先选 L1 大类，再选 L2 细分类。

判定状态

2×2 网格的四个判定按钮：

合格
数据质量达标，可直接使用
修改合格
经修改后质量达标
不合格
质量不达标，需返修或废弃
待定
需进一步确认或讨论

备注与标签

  • 备注框 — 自由文本输入，记录审核意见
  • 快捷标签 — 点击标签药丸自动追加到备注中
  • 标签管理 — 可新增/删除标签，持久化保存到 config/tags.json

保存与提交

  • 仅保存 — 将当前判定结果写入 CSV，不跳转
  • 提交并下一条 — 保存后自动跳转到下一条未审核数据

导航

「上一条」/「下一条」按钮，按当前筛选条件在列表中移动。

数据加载与扫描

扫描规则

系统根据 scan_rules.json 中定义的规则识别数据文件夹：

规则项 默认值 说明
folder_digit_length 8 数据文件夹名称的数字位数（如 8 位数的任务编号）
image_slots ["", "_result"] 图片槽位后缀：基础图（无后缀）和结果图（_result）
text_slots ["_ZH/_CH", "_EN"] 文本文件槽位：中文指令和英文指令

标注员识别

系统从文件夹路径层级中智能提取标注员姓名，支持多种启发式策略：

  • 后缀模式（如 "返修"）
  • 括号模式（如 "[张三]"）
  • 路径层级推断

标注员确认面板

开启后，加载数据时会先弹出确认面板：

  • 显示所有检测到的标注员
  • 可重命名「未知」标注员
  • 可排除特定标注员的数据
  • 确认后才开始正式质检

质检判定操作

单条审核流程

  1. 查看图片 — 在 B 区查看原图和结果图，可切换四宫格或单图模式
  2. 阅读文本 — 检查中英文指令是否正确
  3. 选择分类 — 在 C 区选择 L1/L2 分类
  4. 做出判定 — 点击合格/不合格/修改合格/待定
  5. 添加备注 — 输入审核意见，或点击快捷标签
  6. 附加截图 — 对不合格项粘贴错误截图
  7. 保存/提交 — 点击「提交并下一条」
快捷操作
使用键盘快捷键可大幅提升效率：←→ 切换数据，空格 提交并下一条，1-4 切换图片视图。

L1/L2 分类管理

两级分类体系用于对质检问题进行结构化归类。

使用方式

  1. 在 C 区点击 L1 大类药丸按钮（如 "内容问题"、"格式问题" 等）
  2. 选择 L1 后，下方自动展开对应的 L2 细分类选项
  3. 点击 L2 完成分类选择

管理分类

在 A 区的「分类管理」面板中：

  • 新增 L1 大类
  • 在 L1 下新增 L2 子类
  • 编辑/删除已有分类

分类数据持久化保存在 categories_config.json 中。

快捷标签

快捷标签是预设的常用审核评语，点击即可自动追加到备注框中。

使用方式

  • 在 C 区的标签区域，点击标签药丸即可添加
  • 「常用标签」区域显示高频使用的标签
  • 「全部标签」区域显示所有可用标签

管理标签

  • 输入新标签名称，点击「添加」创建新标签
  • 点击标签右侧的删除按钮移除标签
  • 标签数据保存在 config/tags.json

错误截图

对不合格数据项，可附加最多 3 张 错误截图作为证据。

操作方式

  • 剪贴板粘贴 — 使用系统截图工具（如 Win+Shift+S）截图后，在 C 区按 Ctrl+V 粘贴
  • 文件上传 — 点击上传按钮，从本地选择图片文件

截图以缩略图展示，保存后自动存储到 _00_Evidence_All 文件夹，并在 CSV 中记录路径。

AI 预识别

支持加载 AI 预先质检的结果，作为人工审核的参考。

使用方式

  1. 在 A 区的「AI 预识别」面板，加载 final_report.csv 文件（或手动上传）
  2. 浏览数据时，B 区额外显示 AI 的判定结果
  3. C 区显示 AI 的通过/不通过状态及原因分析
说明
AI 结果仅供参考，最终判定以人工审核为准。AI 预识别不会覆盖人工判定。

抽样验收

当数据量较大时，可使用抽样模式对部分数据进行重点审核。

操作步骤

  1. 在 A 区找到「抽样验收」面板
  2. 设置抽样比例（5% ~ 50%）
  3. 点击「开始抽样」，系统随机抽取对应比例的数据项
  4. 仅显示被抽中的项，专注审核
  5. 完成后点击「退出抽样」，恢复完整列表

合格数据导出

将所有判定为「合格」或「修改合格」的数据文件夹复制到指定输出目录。

  • 输出目录自动以时间戳命名，避免覆盖
  • 保持原始文件夹结构不变
  • 复制完成后自动执行校验

不合格数据归集

将所有判定为「不合格」和「待定」的数据文件夹归集到 {日期}不合格 目录。

  • 采用「先复制后删除」策略，确保数据安全
  • 原始目录结构保持不变

Excel 报告导出

生成 .xlsx 格式的质检报告，包含：

  • 完整的 CSV 数据表（标注员、ID、L1/L2 分类、判定结果、备注、标签、时间戳等）
  • 错误截图作为内嵌图片插入对应行

导出校验

导出完成后可执行校验，系统逐文件对比源目录与目标目录，确认所有文件完整传输。

扫描规则配置

文件位置：scan_rules.json

{
  "folder_digit_length": 8,
  "image_slots": ["", "_result"],
  "text_slots": ["_ZH/_CH", "_EN"]
}
字段类型说明
folder_digit_length整数数据文件夹名称的数字位数
image_slots字符串数组每个数据文件夹中的图片文件后缀列表
text_slots字符串数组文本文件后缀，/ 表示或关系（如 _ZH/_CH 表示匹配 _ZH 或 _CH）

分类配置

文件位置：categories_config.json

{
  "L1": ["内容问题", "格式问题", "标注错误"],
  "L2": {
    "内容问题": ["文字错误", "语义不通", "遗漏内容"],
    "格式问题": ["排版混乱", "图片缺失"],
    "标注错误": ["标签错误", "区域偏移"]
  }
}

也可通过 A 区的「分类管理」面板在界面上直接编辑。

常见问题

Q: 加载文件夹后没有显示数据？

A: 检查 scan_rules.json 中的 folder_digit_length 是否与实际文件夹名位数匹配。确保根目录下存在数字命名的子文件夹。

Q: 图片显示不出来？

A: 确认图片格式为 JPG/PNG，文件未损坏。系统支持 EXIF 自动旋转，但超过 200MP 的图片会被安全策略拒绝。

Q: 导出时提示有缺失 ID？

A: 说明部分数据项尚未保存判定结果。返回列表，筛选「未审核」状态，完成所有审核后再导出。

Q: 快捷键不生效？

A: 确保光标不在文本输入框内（点击空白区域移出焦点），且设置面板中快捷键已启用。

Q: CSV 文件被其他程序占用？

A: 系统使用原子写入策略（临时文件 + 重命名），并有自动重试机制。关闭占用 CSV 的其他程序即可。

Q: 如何切换视图模式？

A: 在 A 区设置面板中切换「四宫格」/「单图对比」模式，或使用数字键 1-4 切换。
